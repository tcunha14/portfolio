PORTFÓLIO TOMÁS CUNHA - VERSÃO COM GESTOR DE PROJETOS

FICHEIROS
- index.html: página inicial, lista de projetos e filtros.
- project.html: modelo que apresenta automaticamente cada projeto.
- projects.json: dados de todos os projetos.
- gestor.html: painel local para adicionar, editar e eliminar projetos.

COMO VER NO COMPUTADOR
A forma mais simples é abrir a pasta no Visual Studio Code e iniciar um servidor local com a extensão Live Server. Depois abre index.html através do Live Server. Abrir index.html diretamente com duplo clique pode impedir o navegador de carregar projects.json por razões de segurança.

COMO ADICIONAR UM PROJETO
1. Abre gestor.html através do Live Server (ou no site publicado).
2. Clica em “Novo projeto”.
3. Preenche o nome, categoria, resumo, descrição e ferramentas.
4. Seleciona uma imagem principal e, se quiseres, várias imagens para a galeria. As imagens são comprimidas e incorporadas nos dados.
5. Clica em “Guardar projeto”.
6. Clica em “Exportar projects.json”. Guarda o ficheiro.
7. Substitui o projects.json antigo na pasta do site pelo ficheiro exportado.
8. Publica a alteração no GitHub Pages (upload/commit do novo projects.json).

COMO EDITAR OU ELIMINAR
No gestor, escolhe Editar ou Eliminar junto ao projeto. Depois de alterações, exporta novamente projects.json.

IMPORTANTE SOBRE PUBLICAÇÃO
O gestor é uma ferramenta de edição local, não uma área de administração online com base de dados. O site público não guarda alterações sozinho. Depois de exportares o projects.json, tens de o substituir no repositório do GitHub e fazer commit. Não publiques informações privadas ou ficheiros CAD confidenciais.

IMAGENS
As imagens selecionadas no gestor são convertidas para JPEG e guardadas em base64 dentro do projects.json. Usa fotografias otimizadas e evita ficheiros enormes. O GitHub Pages tem limites de tamanho do repositório; se tiveres muitas fotografias, é melhor alojá-las como ficheiros na pasta imagens em vez de as incorporar no JSON.

CONTACTO
